# Kinsmen Modern for WHMCS 7.8

This theme adapts the design assets of https://github.com/JosephChuks/kinsmen-modern-whmcs-template (commit 618301d40b9c6961e3e68f45abc9bf5df215b5d7) to the existing WHMCS 7.8 Six templates.

The original Six page templates and Bootstrap 3 runtime are retained. The new header/footer shell provides a fixed desktop sidebar, responsive navigation, the existing account/language/notification controls, and a persistent dark-mode toggle. css/six-compat.css and js/six-compat.js provide compatibility and accessibility adjustments. Upstream v8 templates and account-switch routes were not installed.

The upstream project README is preserved in UPSTREAM-README.md. The baseline Six theme remains available for rollback. This theme changes the client area; the admin Blend theme is separate.
