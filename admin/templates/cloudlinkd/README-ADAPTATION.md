# CloudLinkd admin theme for WHMCS 7.8

Based on https://github.com/cloudlinkd-networks/WHMCS-Dark, commit 987a5f879f0830b66c5db1ca9fcf9cab0653d5e6.

CloudLinkd supplies the dark stylesheet and visual assets. All Smarty page templates and the main JavaScript bundle are taken from the existing Blend 7.8 theme to preserve current payment-method screens, intelligent search, widget actions and form behavior. The logo is adapted to Cloudytek. Original license notices are preserved; the upstream repository license is in LICENSE-UPSTREAM.

Select cloudlinkd in My Account > Template. The original blend theme remains available for rollback. This theme does not modify application data or business logic.
